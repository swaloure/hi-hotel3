# Каталог номеров MAZA из Google Sheets

Сайт читает два листа одной Google-таблицы при каждом открытии страницы города:

- `Алматы` — номера Алматы;
- `Астана` — номера Астаны.

Изменения в таблице появляются без новой сборки сайта.

## Правила

- Первая строка содержит названия колонок.
- Каждая следующая строка — отдельный номер.
- Город определяется названием листа, поэтому колонка `city` не нужна.
- Если у города нет активных строк, блок «Наши номера» на его странице не отображается.
- Чтобы временно скрыть номер, поставьте `FALSE` в `active`.
- Фото должны быть прямыми публичными HTTPS-ссылками на JPG, PNG, AVIF или WebP.
- Поля `name_kz`, `name_en` и другие переводы необязательны: при пустом значении используется русский текст.

## Колонки

| Колонка | Обязательно | Пример | Назначение |
| --- | --- | --- | --- |
| `id` | желательно | `almaty-standard` | Уникальный стабильный идентификатор |

| `sort_order` | нет | `10` | Порядок карточек |
| `name_ru` | да | `Стандарт` | Название номера |
| `name_kz` | нет | `Стандарт` | Название на казахском |
| `name_en` | нет | `Standard` | Название на английском |
| `description_ru` | да | `Уютный номер...` | Описание |
| `description_kz` | нет |  | Описание на казахском |
| `description_en` | нет |  | Описание на английском |
| `area_m2` | да | `24` | Площадь в м², только число |
| `max_guests` | да | `2` | Максимальное количество гостей |
| `bed_type_ru` | желательно | `Двуспальная кровать` | Тип кровати |
| `bed_type_kz` | нет |  | Тип кровати на казахском |
| `bed_type_en` | нет |  | Тип кровати на английском |

| `amenities_en` | нет |  | Удобства на английском |

| `photo2` … `photo10` | нет | `https://...` | Дополнительные фото галереи |

## Подключение

1. Загрузите шаблон Excel в Google Drive и откройте его как Google Таблицу.
2. Назовите листы точно `Алматы` и `Астана`.
3. Откройте доступ «Все, у кого есть ссылка» → «Читатель». Права редактирования оставьте только владельцам.
4. В Google Cloud создайте проект и включите **Google Sheets API**.
5. Создайте API key.
6. Ограничьте ключ:
   - Application restrictions → **Websites**;
   - добавьте `https://maza.kz/*`, `https://www.maza.kz/*`, `https://swaloure.github.io/*` и `http://localhost:*/*`;
   - API restrictions → **Google Sheets API**.
7. Скопируйте ID таблицы из адреса между `/d/` и `/edit`.
8. Создайте `.env.local` на основе `.env.example`:

```env
NEXT_PUBLIC_ROOMS_SPREADSHEET_ID=ID_ТАБЛИЦЫ
NEXT_PUBLIC_GOOGLE_SHEETS_API_KEY=API_KEY
NEXT_PUBLIC_ALMATY_ROOMS_SHEET_RANGE="'Алматы'!A1:AF"
NEXT_PUBLIC_ASTANA_ROOMS_SHEET_RANGE="'Астана'!A1:AF"
```

API key находится в клиентском коде и не считается секретом. Безопасность обеспечивается публичным доступом таблицы только на чтение, ограничением ключа по доменам и разрешением только Google Sheets API.

После первого добавления настроек сайт нужно пересобрать. Дальнейшие изменения строк таблицы появляются без пересборки.
