# Каталог номеров MAZA из Google Таблицы

В одной таблице должны быть шесть листов:

- `Алматы` — номера Алматы;
- `Астана` — номера Астаны;
- `Политика Алматы` — политика для Алматы;
- `Политика Астана` — политика для Астаны;
- `Оферта Алматы` — оферта для Алматы;
- `Оферта Астана` — оферта для Астаны.

Одна строка — один номер. Строки показываются на сайте в том же порядке, что и в таблице.

Если удалить строку, номер исчезнет с сайта. Если на листе нет заполненных строк, раздел «Наши номера» для этого города не показывается.

## Понятные колонки для трёх языков

Текстовые поля заполняются отдельно на русском, казахском и английском. Если перевод на казахский или английский временно оставить пустым, сайт покажет русский вариант.

| Название колонки | Обязательно | Что писать |
| --- | --- | --- |
| `Название номера (русский)` | Да | Например: `Стандарт` |
| `Название номера (казахский)` | Желательно | Например: `Стандарт` |
| `Название номера (английский)` | Желательно | Например: `Standard` |
| `Площадь м²` | Да | Только число: `24` |
| `Количество гостей` | Да | Только число: `2` |
| `Описание номера (русский)` | Да | Обычный текст |
| `Описание номера (казахский)` | Желательно | Описание на казахском |
| `Описание номера (английский)` | Желательно | Описание на английском |
| `Тип кровати (русский)` | Желательно | Например: `Двуспальная кровать` |
| `Тип кровати (казахский)` | Желательно | Например: `Екі кісілік кереует` |
| `Тип кровати (английский)` | Желательно | Например: `Double bed` |
| `Удобства через запятую (русский)` | Да | Например: `Кондиционер, Фен, Сейф, Wi-Fi` |
| `Удобства через запятую (казахский)` | Желательно | Те же удобства на казахском через запятую |
| `Удобства через запятую (английский)` | Желательно | Те же удобства на английском через запятую |
| `Цена за ночь` | Да | Только число без пробелов: `25000` |
| `Валюта` | Нет | Обычно `₸`; если пусто, сайт использует `₸` |
| `Ярлык (русский)` | Нет | Например: `Популярный` или `Новый` |
| `Ярлык (казахский)` | Нет | Например: `Танымал` |
| `Ярлык (английский)` | Нет | Например: `Popular` |
| `Фото 1` | Желательно | Публичная ссылка на фотографию или ссылка Google Drive вида `/file/d/.../view` |
| `Фото 2` … `Фото 10` | Нет | Дополнительные фотографии |

Не переименовывайте эти колонки и листы. Технические колонки, идентификаторы и поле города не нужны.

Для фотографий в Google Drive включите доступ «Все, у кого есть ссылка» → «Читатель». Обычную ссылку из кнопки «Копировать ссылку» можно вставлять прямо в колонки `Фото 1` — `Фото 10`: сайт автоматически преобразует её в прямую ссылку на изображение.

## Политика конфиденциальности и публичная оферта

На каждом из четырёх юридических листов сайт читает только ячейку `A1`:

- на листе `Политика Алматы` вставьте политику Алматы;
- на листе `Политика Астана` вставьте политику Астаны;
- на листе `Оферта Алматы` вставьте оферту Алматы;
- на листе `Оферта Астана` вставьте оферту Астаны.

Внутри ячейки можно использовать переносы строк — сайт их сохранит. Пока текст не готов, оставьте в `A1` фразу `Скоро здесь появится информация.` Если ячейка пустая или Google Таблица временно недоступна, сайт покажет встроенный резервный текст.

Сейчас содержимое `A1` показывается одинаково во всех языковых версиях сайта, а заголовок страницы и кнопка возврата переводятся автоматически.

## Как подключить

1. Загрузите готовый Excel-шаблон в Google Drive и откройте как Google Таблицу.
2. Проверьте названия всех шести листов, перечисленных выше.
3. Откройте доступ «Все, у кого есть ссылка» → «Читатель». Права редактирования оставьте только владельцам.
4. API-ключ Google не нужен: сайт читает только публичный CSV каждой вкладки.
5. Скопируйте ID таблицы из адреса между `/d/` и `/edit`.
6. `gid` вкладок искать и настраивать не нужно: сайт обращается к ним по названиям.
7. При необходимости создайте `.env.local` на основе `.env.example`. Нужен только публичный ID таблицы:

```env
NEXT_PUBLIC_ROOMS_SPREADSHEET_ID=ID_ТАБЛИЦЫ
```

После первого подключения сайт нужно пересобрать один раз. После этого изменения номеров, фотографий, политики и оферты будут появляться без пересборки.
